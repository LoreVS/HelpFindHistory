## What Was Built

**Task 1 — App.css:**
- `:root` now holds light theme defaults: `--bg: #f8f8f8`, `--surface: #ffffff`, `--text: #1a1a1a`, etc.
- New `[data-theme="dark"]` block restores original dark values
- Added `--overlay-bg` and `--grid-line` CSS variables (used by `.compat-legend`, `.seg-legend`, `.canvas-wrap`)
- Fixed `.score-chip` from hardcoded `#161616`/`#2a2a2a`/`#888` to `var(--surface-2)` / `var(--border)` / `var(--text-dim)`
- Fixed `.compat-legend` and `.seg-legend` from hardcoded rgba to `var(--overlay-bg)`
- Fixed `.canvas-wrap` grid lines from hardcoded `rgba(255,255,255,0.018)` to `var(--grid-line)`
- Added `.btn-theme-toggle` and `.btn-theme-toggle:hover` styles

**Task 2 — useTheme hook (`src/hooks/useTheme.js`):**
- Reads localStorage key `pf-theme` on init, defaults to `'light'`
- `useEffect` applies/removes `data-theme="dark"` on `<html>` and persists to localStorage
- Exports `{ theme, toggleTheme }`

**Task 3 — Toggle button in all 3 headers:**
- `CanvasApp` (App.jsx): imports `useTheme`, renders `☾`/`☀` button before END SESSION (conditional on `token`)
- `ProjectsPage`: imports `useTheme`, renders button before END SESSION in `projects-header-right`
- `ProjectDetailPage`: imports `useTheme`, renders button before END SESSION in `detail-header-right`
