**server/routes/attempts.js** — add a new route after the existing `/projects/:id/attempts/me` route:

```
GET /api/attempts/me
```

Returns all attempts for `req.user.id` that have status IN ('published', 'approved', 'rejected'), joined with the project row so the client has `project_name` and `project_status`. SQL:

```sql
SELECT a.id, a.project_id, a.status, a.submitted_at,
       p.name AS project_name, p.status AS project_status
FROM attempts a
JOIN projects p ON p.id = a.project_id
WHERE a.user_id = ?
  AND a.status IN ('published', 'approved', 'rejected')
ORDER BY a.submitted_at DESC
```

Return `res.json(rows)` (always an array, never 404 — empty array is valid).
