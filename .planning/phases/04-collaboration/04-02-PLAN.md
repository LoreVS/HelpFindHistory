```javascript
  /** GET /api/projects/:id/attempts/me — fetch current user's draft (returns null if none) */
  async fetchUserDraft(projectId) {
    try {
      const res = await fetch(`${API}/api/projects/${projectId}/attempts/me`, {
        headers: authHeaders(),
      })
      if (res.status === 404) return null   // no draft yet — not an error
      if (!res.ok) throw new Error(`HTTP ${res.status}`)
      return await res.json()
    } catch (err) {
      console.error('[fetchUserDraft]', err)
      return null
    }
  },

  /** POST /api/projects/:id/attempts — upsert draft layout */
  async saveDraft(projectId, layout) {
    const res = await fetch(`${API}/api/projects/${projectId}/attempts`, {
      method: 'POST',
      headers: { ...authHeaders(), 'Content-Type': 'application/json' },
      body: JSON.stringify({ layout }),
    })
    if (!res.ok) {
      const body = await res.json().catch(() => ({}))
      throw new Error(body.error || `HTTP ${res.status}`)
    }
    return await res.json()
  },

  /** POST /api/attempts/:id/publish — lock attempt as published */
  async publishAttempt(attemptId) {
    const res = await fetch(`${API}/api/attempts/${attemptId}/publish`, {
      method: 'POST',
      headers: authHeaders(),
    })
    if (!res.ok) {
      const body = await res.json().catch(() => ({}))
      throw new Error(body.error || `HTTP ${res.status}`)
    }
    return await res.json()
  },
```

Important notes:
- `fetchUserDraft` treats 404 as a normal "no draft yet" state — returns null, does NOT throw
- `fetchUserDraft` also returns null on network errors (try/catch) — calling code must handle null
- `saveDraft` DOES throw on error — calling component manages error state
- `publishAttempt` DOES throw on error — calling component manages error state
- Do not add new state slices (no `currentDraft`, no `attemptId` in the store state) — these actions return data; the component owns local state
- The `layout` argument to `saveDraft` is passed as-is inside `JSON.stringify({ layout })` — it is the caller's responsibility to serialize the correct shape (array of `{id: dbId, x, y, rotation, scaleX, scaleY}`)
